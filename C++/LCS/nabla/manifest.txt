The enclosed code sample implements nabla, a command-line file comparison utility written in C++20 by Christopher N. Hume.  nabla generalizes the POSIX diff(1) utility: it computes the Longest Common Subsequence (LCS) of two files and renders the result as a unified diff, a CIGAR alignment string, or side-by-side / sequential listings.  It ships four LCS algorithms — Myers (1986), Hunt-Szymanski (1977), Rick (1995), and Rick (2000) — and selects among them either explicitly or automatically.

Programmers make daily use of similar utilities, such as WinMerge, or of source repositories, such as TFS or SVN, to identify edits made to a file by comparing subsequent file revisions.

The code is organized as the C++ namespace lcs and its sub-namespaces, one subdirectory per namespace under lib/:

  lcs                The shared core: the Algorithm enum, the Pair and
                     Delta data structures, the join helper, and the
                     PAIRS / INDEXES / MATCHES typedefs.

  lcs::algorithms    The LCS algorithms: Analysis (automatic dispatch and
                     pathological-case warnings), Myers, HuntSzymanski,
                     RickSpace, and RickTime.

  lcs::files         The comparison driver and its input support: File
                     (the entry point), Encoding, Normal, Options, and
                     Host.

  lcs::formatters    The output formats: Format, Formatter, Cigar, Edit,
                     Parallel, Sequential, RecordDriver, and TextDriver.

  lcs::metrics       Run-time instrumentation: Duration, Progress,
                     ProgressBar, Statistics, and Stopwatch.

  lcs::modes         The comparison granularities: Record (line-by-line)
                     and Text (Unicode code points).

The command-line tool itself — Command, Version, and the SuspectDash helper — sits beside the library and parses the switches.

A simplified, single-module demonstration of the Longest Common Subsequence (LCS) has also been posted in the C++ section (https://rosettacode.org/wiki/Longest_common_subsequence#C.2B.2B) on Rosetta Code.
